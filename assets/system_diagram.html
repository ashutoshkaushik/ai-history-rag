AI History RAG Pipeline

Two halves meet at one Chroma collection. Ingestion runs offline and only re-embeds documents whose fingerprint changed. Each question then runs through a four-node LangGraph flow that can refuse at two points, one of them before any LLM call.

1 · Ingestion (offline)

uv run python -m rag.ingest

2 · Answering a question (LangGraph)

rag_graph.answer_question()
